Setting up a projectConfigurar un proyecto

Start by deciding whether the repository is new or existing. Existing repositories are always audited first; nothing is overwritten without --force.

Primero se decide si el repositorio es nuevo o existente. Los existentes siempre se auditan primero; nada se sobrescribe sin --force.

Daily research loopCiclo diario de investigación

Notebooks are drafts. Code that works moves to src/, gets a test, and passes make check before it is committed. Figures for a paper always come from a script.

Los notebooks son borradores. El código que funciona pasa a src/, recibe una prueba y pasa make check antes del commit. Las figuras del artículo siempre salen de un script.
